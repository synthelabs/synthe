# Set up the weather service

Before you start the weather service on your own computer you must have Node 20 or later installed and you must also have a free account at the weather data provider because the service asks the provider for every forecast that it shows.

## Install

1. Clone the repository.
2. Run `npm install`.

## Configure

Copy `.env.example` to `.env`. Put your provider token in `WEATHER_TOKEN`.
